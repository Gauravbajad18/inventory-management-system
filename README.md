
# Inventory Management System

A Python and MySQL project for managing product inventory.

## Features

- View active products
- Add new products
- Update product prices and stock
- Deactivate products
- Store inventory data in MySQL
- Keep database credentials in a .env file

## Technologies Used

- Python
- MySQL
- mysql-connector-python
- python-dotenv
